# Paarth Infotech favicon

The favicon adapts the existing Pi monogram from `public/brand/logo-reference.png` into a square icon for browser tabs and search results. Generated with the built-in image generator on 19 September 2026; the original output is saved as `favicon-master.png` in this directory.

The deployed sizes are `public/favicon-96x96.png`, `public/apple-touch-icon.png` (180), `public/icon-192.png`, and `public/icon-512.png`. `public/favicon.ico` contains 16, 32 and 48 pixel versions. The old starter `public/favicon.svg` is replaced by an SVG wrapper containing the same logo. These are deterministic format/size exports of the generated master. Keep the deployed icon URLs stable for search crawlers.

## Generation prompt

Use case: logo-brand / precise-object-edit. Create a production favicon asset from the supplied Paarth Infotech logo reference. Preserve the exact recognizable Pi monogram in the TOP LARGE logo: the dark navy stylized uppercase P with its white negative-space arrow pointing upper right, and the lower-case i with its teal split diamond dot. Use the supplied mark, not a newly invented design. Single flat clean icon, centered on a solid pure-white square background, equal balanced approximately 12% safety margin on all sides, mark occupies about 76% of canvas width. Square 1024x1024. Deep navy #10263f P and i stem; teal #007f82 diamond. Clean vector-like hard edges and solid fills. Preserve the arrow cutout and the split across the diamond clearly so they read at very small sizes. No gradients, no glow, no shadow, no texture, no mockup, no 3D, no border. NO wordmark, NO 'Paarth Infotech' lettering, NO '02 / PRECISION', NO sample panels. Output exactly one square app/favicon icon.
